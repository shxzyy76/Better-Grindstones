# Better Grindstones 

A mod where you can use the items that are used to make the tools or armour to repair them on grindstone and if your armour or tool breaks you wont loose it it will just have zero durability and be same as the normal fist and you need to repair it with the help of a grindstone.

Additions:

Added Armour for Wood And Stone

Can be used as a early stage protection

Broken Tools: you wont loose lose tools if they will turn into broken tools but will be nerfed into the power of a fist and can be repaired on grindstone

Grindstone will no longer disenchant the tools.
